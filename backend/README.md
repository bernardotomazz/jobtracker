# Job Tracker

Aplicação full-stack para organizar vagas de emprego, acompanhar processos seletivos e centralizar informações da busca por oportunidades.

> Status: Em desenvolvimento.

## Tecnologias

- Java 21
- Spring Boot
- Spring Security e JWT
- Spring Data JPA
- PostgreSQL
- Flyway
- Docker e Docker Compose
- React, TypeScript, Tailwind CSS e shadcn/ui
